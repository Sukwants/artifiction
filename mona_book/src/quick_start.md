# 快速开始

这份手册保留图文示例，截图可能与当前界面不同。网页内「使用说明」是现行操作说明。

## 导入圣遗物

使用维护中的 [YAS](https://github.com/2745518585/yas/releases) 扫描圣遗物，选择 Mona 导出格式，在圣遗物页面导入生成的 `mona.json`。

首次导入保持删除未扫描物品的选项关闭，导入前确认当前本地账号。导出网页内的 Mona JSON 可以备份圣遗物与收藏夹；计算预设需要单独导出。

Windows 用户也可使用带网页连接功能的 `yas_web_*.zip`：解压后运行「安装网页连接.cmd」，再在网页扫描弹窗中点击「启动并连接 YAS」，按提示授权。安装脚本使用连接包中的程序；如果发布页还没有连接包，先走文件导入。此流程使用 YAS 自带的本机服务。

## 配置计算

进入计算器，选择角色和武器，设置等级、命座、精炼、实际技能等级、敌人及效果触发条件，再选择目标函数和配装约束。

目标函数决定优化什么，例如某次技能伤害或一组攻击的合计。默认配置可作为起点，具体层数、覆盖率和反应条件应与你的玩法一致。更改目标与约束后，最优组合也会变化。

开始计算后比较候选组合，查看属性面板与伤害明细。结果只对当前设置负责，不能把某一目标下的配装直接视为所有场景的最优配装。

## 保存与迁移

把常用设置保存为计算预设，导出预设文件和圣遗物文件。更换浏览器、清除站点数据或换用其他域名前，应保存这些备份。

各本地账号的数据分别导出。导入分享链接依赖远程服务，不能替代离线备份。
