# 介绍

叶师傅开锁铺用于《原神》的伤害计算、圣遗物管理与配装优化。先阅读[快速开始](quick_start.md)；本手册其余章节中的截图和布局来自较早版本，具体入口以当前网页为准。

## 圣遗物优化

工具根据角色、武器、技能、敌人、Buff 与约束条件搜索圣遗物组合。目标可以是某次技能伤害、组合伤害或特定属性，也可使用自定义目标函数。

计算核心由 Rust 实现，以 WebAssembly 在浏览器中运行。计算耗时受物品数量、筛选条件、优化算法和设备影响，不承诺固定耗时。

## 圣遗物潜力

潜力功能分析强化后可能得到的词条状态，并按所选评分标准比较物品。未满级物品的期望分数可高于某件满级物品；这表示强化结果的期望表现，不保证单次强化得到对应词条。

## 自定义目标函数

MONA-DSL 用于描述自定义优化目标，可以在网页 Playground 中实验。语言细节由独立的 DSL 文档维护。

## 扫描与导入

[YAS](https://github.com/2745518585/yas/releases) 在用户电脑上识别游戏背包，导出的 Mona JSON 可以导入工具。带网页连接服务的版本也能直接回传扫描结果；手册快速开始介绍了连接包与文件导入两种方式。

圣遗物、收藏夹与预设默认保存在当前网站的浏览器存储中，请定期导出文件备份。
