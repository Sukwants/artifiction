# 7.2.1

本次补丁处理以下短期问题：

- [#42](https://github.com/Sukwants/artifiction/issues/42)：套装特效列表也展示没有可调参数的效果。计算器只显示当前件数已激活的效果，配置选择界面可以搜索所有效果说明；一件套效果也会显示。
- [#35](https://github.com/Sukwants/artifiction/issues/35)：恢复手动添加圣遗物时主词条选择框的宽度，避免词条名称被挤没。
- [#23](https://github.com/Sukwants/artifiction/issues/23)：在圣遗物页面确认“清空”后，同时删除当前账号的所有已存套装，包括游戏中导入的套装；保留收藏夹及其名称，清除其中的套装引用。其他账号不受影响。原有存储格式不变，无需迁移。
- [#18](https://github.com/Sukwants/artifiction/issues/18)：将全局配置的图标开关改为“联动／独立”文字按钮，提供中英文操作说明和帮助入口，支持键盘操作。配置值与优先级规则不变。

本次不处理 [#14](https://github.com/Sukwants/artifiction/issues/14) 的角色 Buff 完整性与命名核对、[#17](https://github.com/Sukwants/artifiction/issues/17) 的旅行者结构整理、[#30](https://github.com/Sukwants/artifiction/issues/30) 的优化目标权重补全。这些需要逐项核对游戏效果、计算实现与优化行为；部分历史反馈中的 Buff 已在当前代码中实现，不能直接按旧列表批量添加。

版本分支推送会执行项目 CI，无需为检查单独创建 PR。清空场景新增了确认、收藏夹保留和账号隔离的回归检查；同时修复了浏览器测试框架处理 API 错误时引用外部函数导致的异常。实际检查结果以 GitHub Actions 的对应提交记录为准。
