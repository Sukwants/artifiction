# YAS 网页扫描

## 用户：程序从哪里来

YAS 是独立的本机圣遗物扫描程序，维护仓库是 [2745518585/yas](https://github.com/2745518585/yas)。从它的 [Releases](https://github.com/2745518585/yas/releases) 下载支持网页连接的 `yas_web_*.zip`。

连接包由 YAS 的发布流程编译并打包，包含 `yas_artifact.exe`、所需运行库、安装和卸载脚本。安装脚本使用同一解压目录里的程序文件；它不会自行下载 YAS。

源码已经接入网页服务，并不代表某个已发布版本也包含该功能。若发布页没有连接包，请先使用单文件扫描器导出 `mona.json`，在圣遗物页面手动导入。

## 首次连接与扫描

1. 在 Windows 上解压整个连接包，运行「安装网页连接.cmd」，允许管理员权限提示。
2. 打开原神的圣遗物背包，并拉到顶部。
3. 在网页的圣遗物页面点击扫描，选择「启动并连接 YAS」。
4. 允许浏览器打开 YAS、访问本机网络，并在 YAS 的原生授权提示中确认当前网站地址。
5. 选择游戏窗口、最低星级、最低等级和扫描数量，点击「开始扫描并导入」。数量为 0 表示不限制。

成功后网页会显示新增、更新、跳过和删除数量。取消、鼠标右键中断、扫描失败或空结果不会自动导入。删除未扫描到的物品是单独选项，默认关闭；启用后，扫描条件过滤掉的物品也可能被删除。

也可以用管理员终端执行：

```powershell
.\yas_artifact.exe --serve
```

然后在网页点击「连接已运行的 YAS」。这种方式不需要安装唤起协议，服务窗口需要保持运行。

## 安装、更新和卸载

安装脚本会调用 `--install-web`，将程序和运行库复制到 `%LOCALAPPDATA%\YAS\Web`，并为当前用户注册 `yas-scan://` 协议。以后网页按钮就能唤起该目录中的程序。

更新时先关闭正在运行的 YAS 服务，再解压新连接包并运行安装脚本。「卸载网页连接.cmd」移除协议注册；关闭服务后，可以手动删除安装目录。

服务空闲十五分钟后退出，网页失联两分钟或单次扫描超过三十分钟会停止扫描。关闭服务窗口也会结束正在进行的扫描。

## 连接问题

| 现象 | 处理方式 |
| --- | --- |
| 网页按钮没有打开 YAS | 确认安装过连接包，允许浏览器打开外部应用；也可使用 `--serve` 手动启动 |
| 提示无法连接或响应超时 | 检查 YAS 服务窗口和浏览器的本机网络访问权限 |
| 提示拒绝或过期 | 重新连接，在 YAS 授权提示中允许当前网站 |
| 找不到游戏窗口 | 打开游戏，再刷新窗口列表 |
| 扫描识别或翻页错误 | 检查是否处于圣遗物背包顶部，查看扫描日志和 YAS 的窗口/分辨率要求 |
| 更新时无法复制程序 | 先关闭旧 YAS 服务，再运行安装脚本 |
| 浏览器始终不支持连接 | 使用 YAS 导出文件，再从网页手动导入 |

## 维护者：两边如何配套

网页客户端在 `src/pages/ArtifactsPage/YasUIDialog/`：

- `Client.vue`：用户连接和安装说明。
- `webcontrol.ts`：协议唤起、HTTP 请求、令牌与轮询。
- `YasUIDialog.vue`：扫描状态、日志、取消和自动导入。
- `result.ts`：在修改 Store 前校验整批结果。

服务只监听 `http://127.0.0.1:32334`，网页连接协议为 `yas-scan://`。HTTP 接口检查来源与用户授权的令牌；扫描参数是结构化字段，服务端转换为固定的 YAS 扫描选项。接口细节以 YAS 的 `docs/web-bridge.md` 为准，检出子模块后可在 `sub/yas/docs/web-bridge.md` 阅读。

修改接口时要同时检查网页客户端、服务端、协议版本、连接包说明与测试。网页和扫描器分别构建、分别发布；前端 CI 不会启动用户的游戏来验证实际扫描。

`sub/yas` 是 Git 子模块：父仓库记录具体提交，`.gitmodules` 记录仓库地址。服务端改动需要先在 YAS 仓库保存并推送，再在父仓库更新需要的子模块提交引用；仅修改 `.gitmodules` 不会切换到新版代码。YAS 的 Windows CI 使用 nightly 工具链，与本项目 stable 计算核心的环境分开。
