# 使用说明

叶师傅开锁铺根据你设置的角色、武器、技能、敌人和效果条件计算伤害，并从已导入的圣遗物中搜索配装。第一次使用可先完成「选择本地账号 → 导入圣遗物 → 配置角色与目标 → 计算 → 导出备份」。

## 账号与数据

「账号」页面用于把多份圣遗物、收藏夹和计算预设分开保存。导入前确认当前账号；切换账号后看到的是该账号的数据。

这些数据默认保存在当前网站的浏览器存储中。换浏览器、换设备、换域名或清除网站数据后，原有数据不会自动出现。建议用普通浏览器窗口使用，并定期导出备份。

## 导入圣遗物

在圣遗物页面点击「导入」，选择 Mona 格式的 JSON 文件，再确认导入。使用 [YAS](https://github.com/2745518585/yas/releases) 时，选择 Mona 导出格式，导入生成的 `mona.json`。其他工具也应先导出兼容的 Mona 格式。

导入会比较已有圣遗物，跳过相同物品或更新识别到的升级物品。第一次使用建议保持「删除不存在的圣遗物」关闭，确认导入结果后再决定是否需要同步删除。

导入选项的含义：

| 选项 | 行为 |
| --- | --- |
| 删除不存在的圣遗物 | 删除网页中未出现在本次文件中的物品，包括未扫描或被扫描条件过滤的物品 |
| 备份“游戏中导入”收藏夹 | 导入装备信息前，保留原“游戏中导入”收藏夹的备份；关闭时会清理原目录并重新填入本次装备信息 |
| 导入圣遗物套装 | 导入网页导出文件中保存的圣遗物套装与收藏夹信息 |

开始覆盖或删除前，先从圣遗物页面导出当前数据。手动编辑圣遗物后，应重新检查相关套装和计算结果。

## 从网页扫描

网页直接扫描需要 Windows 上的 YAS 本机程序。桌面版圣遗物页面的扫描按钮会打开连接弹窗。

首次使用，从 [YAS 发布页](https://github.com/2745518585/yas/releases) 下载支持网页连接的 `yas_web_*.zip`，解压整个连接包并运行「安装网页连接.cmd」。这个包由 YAS 项目构建，包含扫描程序；安装脚本使用包里的程序，安装一次即可从网页唤起。若发布页没有连接包，可先用普通 YAS 扫描后导入文件。

打开原神的圣遗物背包并拉到顶部，再点击「启动并连接 YAS」。按浏览器提示允许打开应用和访问本机网络，在 YAS 的授权窗口中确认当前网站地址。授权后选择游戏窗口、最低等级、最低星级与数量；数量为 0 表示不限制。

点击「开始扫描并导入」后等待日志和结果。成功时网页自动导入；取消、中断、失败或空结果不会自动导入。可以点击网页的取消按钮，也可以在游戏中用鼠标右键中断。

若已经手动运行 YAS 网页服务，可点击「连接已运行的 YAS」。连接失败时先检查 YAS 窗口与浏览器的本机访问权限；仍无法连接时，继续使用文件导入。

## 配装与伤害计算

进入计算器后，依次确认：

1. 角色与武器、等级、命座、精炼，以及实际生效的技能等级。
2. 敌人的等级和抗性、反应类型及相关触发条件。
3. 角色效果、武器被动、套装与 Buff 的层数、覆盖率和开关。
4. 优化目标、套装或主词条等约束，以及可供搜索的圣遗物。

目标函数决定优化的指标。例如，某次技能的伤害最优和一轮多段攻击的总伤害最优，可能得到不同配装。默认值可以作为起点，具体配置仍应按你的玩法调整。

开始计算后，比较候选组合，并用属性面板和伤害明细检查效果来源。若结果与游戏或其他工具差异较大，先对齐技能、反应、敌人、Buff 与输出类型，例如暴击伤害和期望伤害。

整队优化用于协调多人配装。圣遗物潜力用于比较强化结果的期望表现；未满级圣遗物分数较高，表示它在当前评分标准下有较高期望，不保证一次强化获得相应词条。

## 计算预设与圣遗物套装

计算预设保存常用的计算设置。可以从计算器保存，再到「计算预设」页面查看、导入或导出。套装与收藏夹则用来组织具体圣遗物组合，两者需要分别维护。

应用预设后检查命座、武器、技能等级和效果条件是否适合当前账号。分享给其他人时说明使用场景，避免把一次计算的配置当成所有玩法的默认配置。

## 备份、恢复与分享

备份当前账号时：

1. 在「圣遗物」页面导出 Mona JSON，保存圣遗物与收藏夹。
2. 在「计算预设」页面导出全部预设。
3. 如果使用多个本地账号，切换到每个账号分别导出，并在文件名中区分。

恢复时先选择或创建对应账号，再分别导入圣遗物和预设。文件导入涉及覆盖或删除选项时，先备份现有内容。设置页面的清空本地存储会清除网站保存的数据，只有准备重新开始或已有备份时再使用。

分享链接会把相应内容上传到远程服务，服务不可用时链接可能无法创建或读取。跨设备迁移和长期备份优先保存导出文件。

## 全局配置联动

一些角色、Buff 或目标函数共用同一个参数。配置右上角的绑定图标显示联动状态：蓝色表示已绑定，灰色表示未绑定。点击可切换。

绑定时，修改一处会更新同组配置的生效值；存在多个配置来源时，系统按优先级选择生效来源。取消绑定后，该处可以使用独立设置。如果某个值随另一处变化，先检查绑定状态。

悬停在绑定图标上可以查看联动参数和优先级。这些设置用于表达同一场景中的共享条件，计算前应确认它们与你的实际玩法一致。

## 常见问题

| 问题 | 可以先做什么 |
| --- | --- |
| 数据突然不见了 | 检查账号、网站域名、浏览器和窗口模式，确认是否清理过网站数据，再尝试导入备份 |
| 导入提示格式错误 | 确认文件是 Mona 圣遗物 JSON，预设文件应从预设页面导入 |
| 有些圣遗物没有进入结果 | 检查扫描条件、配装筛选和约束，以及是否已导入到当前账号 |
| 扫描连接失败 | 检查是否安装了支持网页连接的版本，并允许打开 YAS 和访问本机网络 |
| 计算没有候选组合 | 放宽套装、主词条等约束，检查各部位是否有可用圣遗物 |
| 计算很慢或超时 | 缩小候选范围、检查优化设置；设备性能和物品数量会影响耗时 |
| 伤害和游戏内不一致 | 对齐技能等级、效果条件、反应、敌人抗性和伤害类型，查看明细 |
| 分享链接不可用 | 尝试文件导入导出，并检查远程服务是否可用 |

反馈问题时请附上页面、版本、复现步骤、预期与实际结果，以及尽可能小的预设或圣遗物样例。[项目仓库](https://github.com/Sukwants/artifiction)的 README 提供维护文档与问题反馈入口。
